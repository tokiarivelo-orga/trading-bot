## 🎬 4. How to Record the MP4 Walkthrough Video with Playwright

Yes! You can automatically generate a clean, professional MP4 video of the full workflow tour using **Playwright**.

We have created an automated recording script located at `scripts/record_demo_tour.py` (and instructions below) that launches Chromium, automatically navigates across every single page in your frontend with human-like mouse animations and scrolling, and outputs a high-definition video!

### Technical Explanation of Playwright Video Recording

When configuring Playwright's browser context, video recording is natively supported via the `record_video_dir` and `record_video_size` parameters:

```python
# Python Playwright setup for HD Video Recording
browser = playwright.chromium.launch(headless=False, slow_mo=300)
context = browser.new_context(
    viewport={"width": 1920, "height": 1080},
    record_video_dir="./videos/demo_tour",
    record_video_size={"width": 1920, "height": 1080}
)
page = context.new_page()
# Perform tour actions...
context.close()  # Video is saved cleanly upon context close!
```

### Quick Commands to Record Your Video

1. **Start your backend and frontend servers:**
   ```bash
   make dev
   ```
2. **Run the Playwright video recording script in a new terminal:**
   ```bash
   python3 scripts/record_demo_tour.py
   ```
3. **Convert to MP4 (if necessary):**
   Playwright natively exports high-quality `.webm` video files. To convert to `.mp4` for maximum compatibility on Facebook & LinkedIn Ads, run:
   ```bash
   ffmpeg -i videos/demo_tour/walkthrough.webm -c:v libx264 -preset slow -crf 18 -c:a aac videos/demo_tour/AI_Trading_Bot_Ad_90s.mp4
   ```
